# Maya Viewport 2.0 STMap Lens Distortion

## Tested environment
**Windows 11**
**Maya 2026 / OpenGL Core Profile**

## STMap
- Only STMaps following [Foundry's STMap definition](https://learn.foundry.com/nuke/content/reference_guide/transform_nodes/stmap.html) are supported.
- Raw, floating-point EXR; 32-bit float is recommended.
- If the dataWindow extends beyond the displayWindow, compare the displayWindow width and height with Render Settings. Otherwise, compare the dataWindow width and height.

## Current limitations

- One static STMap, shared by all panels using this override.
- OpenGL Core Profile only; DX11, legacy OpenGL, and stereo are not supported.
- An 8-bit RGBA screen render target for viewport preview, not HDR final rendering.
- No animated STMap.
- Bilinear filtering.

## Playblast
Both regular playblast and `offScreen=True` were tested on this environment.

## Install, uninstall, and open
**Install**
1. Download the repository.
2. Drag the root `install.py` into a Maya viewport.
3. After installation, the Script Editor prints the following Python code. Run it to open the UI:

```python
import lens_ui
lens_ui.show()
```

**Uninstall**
Drag the root `uninstall.py` into a Maya viewport, then restart Maya.
